# Zeno ERP — مشخصات دیزاین داشبورد (نسخه 1.0)

این بسته همه مقادیر داشبورد فعلی را برای کدنویسی واقعی دارد. همه اعداد از صفحه نشرشده (Main.dc.html) اندازه‌گیری شده‌اند.

| فایل | کاربرد |
|---|---|
| `zeno-tokens.css` | متغیرهای CSS (رنگ، فونت، فاصله، گوشه، سایه) + کلاس‌های آماده همه اجزا |
| `zeno-tokens.json` | همان توکن‌ها به شکل JSON برای Tailwind، Flutter، React Native یا هر فریم‌ورک دیگر |
| `dashboard-reference.html` | نمونه کامل داشبورد که فقط با همین CSS ساخته شده؛ در مرورگر باز کنید |

---

## 1. قواعد کلی
- **جهت:** همه‌جا RTL است. دکمه بستن همیشه سمت راست قرار دارد.
- **پول:** علامت ارز سمت چپ مبلغ است: `؋ 1,250`. کلاس `.money` با `.cur` این کار را انجام می‌دهد.
- **فونت اعداد:** اعداد، کدها و تاریخ‌ها با فونت Inter و `tabular-nums` نوشته می‌شوند.
- **عنوان‌ها:** عنوان‌ها یک‌کلمه‌ای یا کوتاه هستند و هیچ معلوماتی تکرار نمی‌شود.
- **فلتر:** فلترها داخل یک آیکن (`tune`) قرار دارند.
- **حذف:** هیچ رکوردی حذف نمی‌شود، فقط **ابطال** می‌شود.
- **بدهکار و طلبکار:** بدهکار سرخ است و طلبکار سبز.
- **مقادیر KPI:** هرگز کوتاه یا پنهان نمی‌شوند.

   - خزانه 320px سمت راست؛ هشدارها بقیه عرض.

## 6. اجزا

### منوی کناری
- **آیتم:** ارتفاع 38، padding `0 10px`، گوشه 10، فاصله 10، فونت 13/500، آیکن 20px، رنگ `#B7C1DB`.
- **هاور:** زمینه `#132042` و متن سفید.
- **فعال:** گرادیانت `90deg rgba(47,111,237,.10 → .32)`، متن سفید 700، نوار آبی 3px در کنار.
- **نشان عددی:** 20×20، گوشه 10، Inter 10.5/700، آبی (برای اعلان سرخ `#DC2626`).
- **دکمه POS:** ارتفاع 38، گوشه 10، آبی با سایه brand.

### عنوان بخش و ساعت
- **عنوان:** 14px/800، رنگ ink، حداقل ارتفاع 30.
- **ساعت:**
  - آیکن `schedule` به اندازه 16px و آبی.
  - زمان با Inter 13/800 و letter-spacing .3.
  - یک خط جداکننده 1×14.
  - تاریخ 12/600 کم‌رنگ.
  - بدون حاشیه.

### کارت KPI (مات)
- padding `11px 13px`، گوشه 14، فاصله 10.
- **خانه آیکن:** 34×34، گوشه 10، آیکن پر 16px.

## 8. نکات پیاده‌سازی
- **حالت تاریک:** `data-theme="dark"` را روی `<html>` بگذارید. همه رنگ‌ها خودکار عوض می‌شوند.
- **رنگ ماژول در کارت جدید:** با `data-hue="sale|receive|purchase|product|expense|exchange|profit"` یا با `style="--c: #hex"` یا `--g` رنگ بدهید.
- **Tailwind:** مقادیر `zeno-tokens.json` را در `theme.extend` (colors، fontSize، borderRadius، boxShadow) بگذارید.
- **مرورگرهای قدیمی:** برای `color-mix` در مرورگرهای خیلی قدیمی، رنگ‌های مات را از جدول بالا از پیش حساب کنید.
